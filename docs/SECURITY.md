## 外部服务与测试隔离

- AI、工商和百度搜索调用会记录供应商、耗时、状态和错误类型，但不会记录 API Key、完整请求体或完整响应体。
- 只有网络、限流和临时服务错误会自动重试；鉴权失败和参数错误不会循环请求。
- Playwright 使用临时的 `BOSS_WORKBENCH_TEST_MODE=1`，返回确定性测试结果，不访问真实供应商，也不会产生外部 API 费用。

## SQLite 备份与恢复

- SQLite 迁移前会创建时间戳备份，备份文件保存在本地 `data/storage/backups/`。
- 设置页的恢复预览只执行路径校验、SQLite 完整性检查和 schema 版本读取，不会自动覆盖当前数据库。
- 备份文件可能包含简历、岗位和日志等敏感业务数据，应与完整数据备份一样存放在可信位置。

## 完整备份与脱敏备份

- 完整备份用于个人迁移、恢复和本机长期备份，可能包含简历、岗位、尽调、日志和配置数据，只应保存在可信位置。
- 脱敏备份用于演示、问题排查和交付验收，会隐藏常见密钥字段、手机号和邮箱。
- 脱敏备份只导出文本类文件；PDF、图片、SQLite 数据库等二进制文件会跳过，因为这些文件无法在当前流程中可靠脱敏。
- 若需要把数据发给他人排查问题，优先使用脱敏备份，并在发送前人工打开确认一次。

项目会对 AI、百度搜索、腾讯云工商 API 配置进行本地加密保存。

- 优先使用环境变量 `BOSS_WORKBENCH_SECRET_KEY` 作为加密主密钥。
- 未设置环境变量时，系统会自动生成 `data/.secret_key`。
- `data/` 目录不会提交到代码仓库，避免真实配置和个人数据进入发布包。

请妥善保留当前使用的主密钥。若 `data/.secret_key` 丢失，或更换了 `BOSS_WORKBENCH_SECRET_KEY`，旧的加密配置将无法解密，需要重新录入。

## 密钥轮换流程

1. 在设置页导出当前配置。若需要完整密钥，使用完整导出确认流程。
2. 停止后端服务。
3. 备份当前 `data/` 目录，尤其是 `data/.secret_key`。
4. 设置新的 `BOSS_WORKBENCH_SECRET_KEY`，或移走旧的 `data/.secret_key` 让系统重新生成。
5. 重新启动后端。
6. 在设置页重新保存 AI、百度搜索、腾讯云工商 API 配置，或导入包含完整密钥的配置备份。
7. 分别点击各 API 的测试按钮，并查看上线体检结果。

## 发布前检查

发布前运行：

```bash
python3 scripts/release_check.py
```

如只想预览检查项：

```bash
python3 scripts/release_check.py --dry-run
```

该脚本会执行后端测试、前端校验和 Git 差异格式检查。

脚本还会执行本地明文密钥扫描，检查 `data/provider.json`、`data/baidu_config.json`、`data/business_info_config.json` 中是否仍存在未加密字段。若扫描失败，请重新在设置页保存对应 API 配置，让系统写入加密字段后再发布。

## 维护面板检查项

设置页的完整数据维护区提供：

- 发布清单：展示本版本需要通过的质量门禁。
- 上线人工验收清单：覆盖核心求职流程、打招呼流程和上线安全检查。
- 安全审计：检查本地加密主密钥和常见配置文件中的明文密钥风险。
- 存储状态：展示当前岗位池主存储是 JSON 还是 SQLite，并支持切换。
- 导出隐私扫描：检查简历、上传文件和招呼语目录中是否可能包含手机号或邮箱。
- 真实依赖审计：可在维护区运行前端 `pnpm audit`，并在安装 `pip-audit` 后运行后端依赖漏洞审计。
- SQLite 迁移向导：展示备份、迁移、校验、设主存储和回滚路径的步骤状态。

## 启动前检查

启动脚本会先运行：

```bash
python3 scripts/launcher_preflight.py
```

该检查会确认 Python、pnpm、前端构建产物、数据目录和 5173 端口状态。端口占用会以警告形式提示，脚本仍会继续由启动流程处理。
