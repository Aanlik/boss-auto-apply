# 新人 API 配置指南

本指南帮助你为“boss 求职助手”完成从注册、充值/订阅、创建密钥到应用内测试的配置。

> 推荐顺序：先配置 **DeepSeek**，即可使用 AI 简历分析、JD 分析、公司尽调总结、岗位排序和话术生成；再按需配置百度千帆搜索和腾讯云工商 API，增强公司尽调的信息完整度。

## 先看这张表

| 服务 | 是否必需 | 在项目中的作用 | 需要准备 |
| --- | --- | --- | --- |
| DeepSeek 开放平台 | 建议优先配置 | 简历、JD、尽调、排序、话术等 AI 生成 | API Key、可用余额 |
| 百度智能云·千帆 AI 搜索 | 可选 | 尽调时搜索公开网络信息并生成带引用的摘要 | 千帆 API Key；按量调用权限 |
| 腾讯云市场企业工商 API | 可选 | 尽调时查询结构化工商数据 | 已购商品对应的资源实例 `SecretId`、`SecretKey` |

**密钥安全原则**：Key 只粘贴到应用的“设置”页；不要发到聊天、截图、Issue、邮件或公开文档。完整配置备份会包含密钥，只能存放在自己可信的加密位置。

## 一、DeepSeek：完成核心 AI 能力

### 1. 注册与登录

1. 打开 [DeepSeek 开放平台](https://platform.deepseek.com/)。
2. 按页面提示注册或登录；若页面要求实名认证，请按实际主体完成。
3. 确认当前登录的是准备充值和创建 Key 的同一账号。

> DeepSeek 的 API 调用与聊天产品的会员/订阅不是同一件事。项目需要的是**开放平台 API 余额和 API Key**。

### 2. 充值

1. 在开放平台进入“充值”。
2. 按页面可用方式完成充值（官方 FAQ 列出的在线方式包括支付宝、微信等；实际可用方式以账户页面为准）。
3. 在“账单”或余额页确认充值到账后，再创建或使用 API Key。

DeepSeek 按 token 用量扣费；模型价格和活动会变动，请以 [官方模型与价格页](https://api-docs.deepseek.com/zh-cn/quick_start/pricing) 为准。官方说明中，充值余额不会过期，赠送余额的有效期以账单页面为准。

### 3. 创建 API Key

1. 在开放平台进入 **API Keys**。
2. 点击“创建 API Key”，填写易识别的名称，例如 `boss-求职助手-个人电脑`。
3. 创建后立即复制并保存在密码管理器中。离开创建页后通常无法再次查看完整 Key；遗失时请新建并删除旧 Key。

### 4. 在本项目中填写

1. 打开应用右上角 **设置**。
2. 在“AI 供应商”区域选择 **DeepSeek**。
3. 填写：

   | 设置项 | 填写值 |
   | --- | --- |
   | API Key | 刚创建的 DeepSeek API Key |
   | Base URL | `https://api.deepseek.com`（选择 DeepSeek 后会自动带入） |
   | 模型 | 优先选 `deepseek-v4-flash`；需要更高质量时可选 `deepseek-v4-pro` |

4. 点击“保存”，再点击“测试连接”。显示连接成功后即可使用。

本项目使用 OpenAI 兼容接口；上述 Base URL 与当前模型名均来自 [DeepSeek 首次 API 调用文档](https://api-docs.deepseek.com/quick_start/your_first_api_call)。排序模块会优先请求 JSON 输出模式，并会在服务不支持时自动回退。

### 5. 常见报错

| 现象 | 优先处理 |
| --- | --- |
| `401` / 认证失败 | 确认粘贴的是 API Key，不是登录密码；检查账号与 Key 是否一致；重新创建 Key 后保存。 |
| `402` / 余额不足 | 在开放平台“充值”或账单页确认可用余额。 |
| `429` | 暂停后重试；不要同时重复点击排序。应用已限制排序并发。 |
| `500`、`503` | 先等待一段时间再重试；持续出现时查看 DeepSeek 服务状态或联系官方支持。 |
| “返回内容无法解析” | 先升级至最新版应用后重试；若仍存在，保留 `runtime.log` 中的脱敏诊断信息反馈。 |

错误码含义以 [DeepSeek 官方错误码](https://api-docs.deepseek.com/zh-cn/quick_start/error_codes/) 为准。

## 二、百度千帆：为公司尽调增加公开网络搜索

### 1. 注册、开通与计费

1. 登录 [百度智能云千帆控制台](https://console.bce.baidu.com/qianfan)。没有账号时按页面引导注册并完成认证。
2. 打开千帆相关控制台，确认可使用千帆 API/模型资源。
3. 百度智能搜索有免费额度，且支持按量后付费；为避免额度耗尽导致尽调中断，可按官方页面开通后付费。免费额度和价格可能调整，使用前查看当前 [智能搜索生成计费说明](https://cloud.baidu.com/doc/qianfan-api/s/Hmbu8m06u)。

### 2. 创建 API Key

1. 在百度智能云控制台进入 **安全认证 → API Key**。
2. 点击“创建 API Key”。
3. 按官方认证指引选择千帆对应资源（官方文档示例为“千帆 ModelBuilder”），创建并复制 Key。

千帆 API Key 的创建和鉴权流程见 [官方认证鉴权文档](https://cloud.baidu.com/doc/qianfan-api/s/ym9chdsy5)。

### 3. 在本项目中填写

1. 打开应用 **设置**。
2. 找到“百度千帆智能搜索”。
3. 将千帆 API Key 粘贴到唯一的 **API Key** 输入框，点击“保存”。
4. 点击“测试连接”。成功后，公司尽调会使用千帆搜索公开网络信息并整理引用。

这里**不需要填写 Base URL 或模型名**。项目已使用千帆智能搜索接口 `https://qianfan.baidubce.com/v2/ai_search/chat/completions` 和 Bearer API Key 鉴权；接口说明见 [官方智能搜索生成文档](https://cloud.baidu.com/doc/qianfan-api/s/Hmbu8m06u)。

### 4. 注意事项

- 千帆搜索是尽调增强项；没有配置时，DeepSeek 的核心 AI 流程仍可使用。
- 搜索结果是公开网络信息的汇总，不等同于事实结论。公司尽调中的来源和风险应人工复核。
- 若提示 `401`，先检查 Key；若提示额度或 `429`，检查可用额度和调用频率。

## 三、腾讯云市场：为公司尽调增加工商数据

### 1. 注册与订阅/购买

1. 登录 [腾讯云](https://cloud.tencent.com/)，按页面要求完成实名认证。
2. 在 [腾讯云市场](https://market.cloud.tencent.com/products/28760) 打开本项目对应的“企业工商全量查询”商品。
3. 选择适合自己的调用套餐或规格，提交订单并完成支付。
4. 支付成功后，进入“已购产品与服务”，打开该商品的资源实例或“管理”页面。

腾讯云市场的通用购买流程、订单和资源实例入口参见 [官方购买 API 类商品文档](https://cloud.tencent.com/document/product/306/31780)。套餐价格、配额、续费方式和商品能力以该商品页面为准。

### 2. 获取资源实例密钥

在**已购产品对应的资源实例页面**复制：

- `SecretId`
- `SecretKey`

> 重要：这里需要的是**云市场商品资源实例**的密钥，不是腾讯云账号的 CAM 访问密钥，也不是其他 API 商品的密钥。若密钥与购买的商品不匹配，云市场网关可能返回 `427`。

腾讯云云市场 API 采用密钥对鉴权，`SecretId` 用于标识，`SecretKey` 用于签名且不会在请求中明文传递。详情见 [腾讯云 API 网关密钥对认证文档](https://cloud.tencent.com/document/product/628/11819)。

### 3. 在本项目中填写

1. 打开应用 **设置**。
2. 找到“腾讯云企业工商 API”。
3. 填写：

   | 设置项 | 填写内容 |
   | --- | --- |
   | 资源实例 SecretId | 云市场该工商商品资源实例中的 `SecretId` |
   | 资源实例 SecretKey | 同一资源实例中的 `SecretKey` |
   | API 端点 | **通常留空**，应用会使用该商品的默认端点 |

4. 点击“保存”，再点击“测试连接”。成功时会返回一条测试企业的名称、法人和经营状态。

只有在你订阅了与默认商品**完全兼容**、且服务商明确给出替代端点的情况下，才填写“API 端点”。不要把任意腾讯云 API、个人接口或网页地址填进这里。

### 4. 常见报错

| 现象 | 优先处理 |
| --- | --- |
| 未配置 SecretId / SecretKey | 两项必须同时填写并保存。 |
| `401`、`402`、签名校验失败 | 确认两个值来自同一资源实例，粘贴时没有空格或换行。 |
| `427` | 密钥和已购商品不匹配；回到该商品的资源实例重新复制。 |
| `429` 或配额耗尽 | 在“已购产品与服务”查看套餐调用量，按商品规则续费或升级。 |
| 端点不可用 | 清空自定义端点，先恢复应用默认端点；如仍失败，按商品 API 调用说明核对端点。 |

腾讯云市场网关错误含义可参考 [官方网关操作说明](https://cloud.tencent.com/document/product/306/107687)。

## 四、推荐的首次验证流程

1. 只配置 DeepSeek，点击“测试连接”。
2. 上传或确认简历，选择 1–3 个岗位，执行一次 JD 分析或排序，确认可生成结果。
3. 配置百度千帆并测试连接；对 1 家公司运行尽调，确认能看到网络搜索摘要与引用。
4. 配置腾讯云工商 API 并测试连接；再对 1 家公司运行尽调，确认工商字段已补充。
5. 所有服务都通过后，再扩大到批量尽调或批量排序。

这样能把配置、额度和网络问题限制在小范围内，避免一次批量任务消耗过多额度。

## 五、配置后的安全与维护

- 应用会将 API Key、SecretKey 在本地加密保存；设置页只显示打码值。
- 如怀疑密钥泄露：立即到对应平台删除/轮换密钥，再回到应用“清除”旧配置并保存新 Key。
- “导出脱敏配置”不含完整密钥；“导出完整配置”含密钥，切勿分享。
- 运行问题请先在设置页点击“测试连接”，再查看本地数据目录 `logs/` 中的日志。提交给他人排查前，务必脱敏。
