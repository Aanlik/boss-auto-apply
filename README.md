# boss 求职助手

`boss 求职助手` 是一个本地运行的桌面求职工作台，围绕 BOSS 直聘求职流程提供岗位管理、JD 补全、公司尽调、岗位排序、简历优化、打招呼话术和进度复盘能力。

它适合希望系统化管理求职过程的用户：先抓取和整理岗位，再分析公司与 JD，随后根据简历匹配度和个人偏好排序，最后生成更贴合岗位的简历与沟通话术。

## 功能模块

### 仪表盘

- 查看求职流程状态、关键指标、求职漏斗、趋势和 CRM 看板。
- 管理失败任务，支持重试、删除和清空。
- 查看 AI 版本记录，支持折叠、刷新、删除和清空。
- 自定义仪表盘板块显示和排序。

### 简历

- 上传、解析和维护简历信息。
- 使用 AI 重新解析、评估和优化简历。
- 保存简历版本并进行版本对比。
- 预览、生成和下载 PDF 简历。
- 保留简历优化记录和简历聊天记录。

### 岗位

- 检查 BOSS 登录状态。
- 按城市、关键词和筛选条件抓取岗位。
- 导入、筛选、标记、删除和导出岗位。
- 管理搜索预设、企业黑名单、岗位标签和岗位状态。
- 检查岗位池质量，包括缺失 JD、重复岗位、疑似过期岗位和黑名单命中。
- 抓取 JD 时默认跳过已有 JD 的岗位，也可手动重新抓取。

### 公司尽调

- 对已选岗位执行 JD 分析和公司尽调。
- 根据岗位状态自动判断下一步操作。
- 汇总工商信息、搜索证据、AI 风险判断、行业趋势和用户备注。
- 支持公司尽调结果导出。

### 排序

- 根据简历匹配度、JD 分析、公司风险、用户偏好和权重模板生成岗位排序。
- 展示推荐理由、风险点和行动建议。
- 支持权重策略调整、用户反馈和排序结果导出。

### 打招呼

- 基于已选岗位生成打招呼话术。
- 支持按岗位范围批量选择、生成、重新生成、复制和校验话术。
- 支持 AI 优化简历、PDF 预览、模板推荐和下载。
- 支持人工确认发送、记录 HR 回复和跟进提醒。
- 自动发送前执行登录检查、话术校验、页面检查、频率限制和最终确认。
- 批量发送会过滤已标记为已打招呼的岗位。

### 设置与帮助

- 配置 AI Provider、百度千帆搜索、工商数据接口和用户偏好。
- 导入导出配置，管理备份、恢复和维护检查。
- 查看按模块整理的帮助内容、推荐步骤、完成信号和常见问题。

## 技术栈

- 前端：React、TypeScript、Vite、Vitest、Playwright。
- 后端：FastAPI、Pydantic、本地 JSON/SQLite 存储、ReportLab、Pillow。
- 桌面端：Electron、electron-builder。
- 外部服务：OpenAI 兼容 AI Provider、百度千帆智能搜索、腾讯云云市场工商 API。
- 浏览器自动化：通过本机浏览器执行正常页面操作。

## 本地运行

安装并构建前端：

```bash
cd frontend
pnpm install --frozen-lockfile
pnpm build
```

安装后端依赖：

```bash
cd backend
python3 -m pip install -e .
```

从项目根目录启动：

```bash
./start.sh
```

访问地址：

```text
http://127.0.0.1:5173
```

服务默认只监听本机地址。

## 常用命令

## 数据存储

源码开发模式默认使用本地数据目录：

```text
~/.boss-auto-apply
```

主要业务数据由后端持久化，包括：

- 岗位池和岗位状态。
- 已选岗位。
- 当前简历和简历文件。
- JD 分析结果。
- 公司尽调报告。
- 排序结果。
- 打招呼草稿、发送记录、回复记录和跟进提醒。
- AI 优化记录、AI 聊天记录、AI 版本记录和设置项。

界面偏好会保存在浏览器本地，例如当前页面、板块布局和部分折叠状态。

## 安全边界

- 应用默认只允许本机访问；局域网访问需要显式配置。
- BOSS 相关操作只执行正常浏览器页面流程。
- 应用不会绕过登录、验证码或平台风控。
- 遇到登录失效、验证码、页面风控、页面结构变化或连续失败时会停止操作。
- 自动打招呼真实发送前需要用户确认。
- 建议先小批量验证，再扩大自动化范围。

## 推荐流程

1. 在“设置”中配置 AI、搜索、工商数据接口和个人偏好。
2. 在“简历”中上传或完善简历。
3. 在“岗位”中登录 BOSS 并抓取岗位。
4. 补全岗位 JD，处理重复、过期和黑名单岗位。
5. 在“公司尽调”中分析 JD 和公司情况。
6. 在“排序”中生成岗位优先级。
7. 在“打招呼”中生成话术和优化简历。
8. 小批量确认发送，并在仪表盘跟进进度。
